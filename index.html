What are Sequential Circuits?

Unlike combinational logic circuits whose output values depend solely on their current inputs (e.g., AND/OR gates), sequential circuits contain memory elements.

Their output is determined by both the current inputs and the history of past inputs. This memory capability is achieved using basic storage units called Flip-Flops synchronized by a periodic clock signal.

Synchronous

State changes occur simultaneously triggered by a single shared system clock pulse.

Asynchronous

State changes cascade consecutively without a centralized clock. Simple but slower.

Shift Registers

A group of D Flip-Flops connected in series (cascade). Data moves one position per clock pulse.

🔑 Core Idea: Think of a shift register like a queue of people — on each "clock bell", everyone passes their item to the next person. The new item enters at the front (FF0), and the last person's item (FF3) exits or becomes available as output.
SISO

Serial-In Serial-Out. 1 input pin, 1 output pin. Data enters bit-by-bit at FF0 and exits bit-by-bit from FF3. Takes N clock pulses to shift an N-bit word completely through. Used as a time-delay element.

SIPO

Serial-In Parallel-Out. 1 input pin, 4 output pins (Q0–Q3). After N clock pulses, all bits are visible at outputs simultaneously. Used to convert serial data → parallel data (e.g. UART receiver).

PISO

Parallel-In Serial-Out. 4 input pins (I0–I3), 1 output pin (Q3). All bits loaded at once in one clock, then shifted out one-by-one. Used to convert parallel data → serial data (e.g. SPI transmitter). Output order: I3 first, then I2, I1, I0.

PIPO

Parallel-In Parallel-Out. 4 input pins, 4 output pins. In ONE clock pulse, all inputs are simultaneously transferred to all outputs. Acts as a temporary register / data buffer. Fastest type.

Binary Counters

Sequential circuits that cycle through a fixed sequence of binary states on each clock pulse. Built from JK or T Flip-Flops.

🔑 Core Idea: A counter is like a digital odometer. Each clock tick advances it by 1. When it reaches its maximum value (MOD-N limit), it resets to 0 and starts again. The binary outputs Q3 Q2 Q1 Q0 represent the current count in binary.

⚡ Asynchronous (Ripple) Counter

  • Only FF0 receives the master clock directly
  • FF1 is clocked by Q0's output; FF2 by Q1; FF3 by Q2
  • State changes "ripple" through each stage one-by-one
  • Each FF adds a small propagation delay (~10–20ns)
  • Can produce glitches (momentary wrong values) during transitions
  • Simple circuit, fewer gates — good for low-speed applications

🚀 Synchronous Counter

  • All flip-flops share the same clock line simultaneously
  • Every FF triggers at exactly the same rising clock edge
  • No ripple delay accumulation — all bits update simultaneously
  • No glitches during transitions
  • Needs extra logic (AND gates for carry lookahead) but much faster
  • Used in CPUs, FPGAs, high-speed digital systems

Ring Counter

A circular shift register where the output of the last flip-flop feeds directly back into the input of the first.

🔑 Core Idea: Imagine 4 people in a circle passing a single ball. Only one person holds the ball at a time. On each clock pulse, the ball moves one step clockwise. That ball is the "1" bit — it circulates forever!

How It Works

  • Built from N D Flip-Flops connected in a ring (series)
  • Initialized with exactly one "1" bit (e.g. Q0=1, Q1=Q2=Q3=0)
  • Feedback: Q3 output connects directly to D0 input (no inversion)
  • On each rising clock edge, every flip-flop copies its left neighbour
  • The "1" rotates: Q0→Q1→Q2→Q3→Q0→... endlessly
  • 4-stage ring counter has exactly 4 unique states (= N states)
  • Acts as a divide-by-N frequency divider

Sequence: 1000 → 0100 → 0010 → 0001 → repeats

⚠️ Important Limitation: A 4-bit ring counter has only 4 valid states out of 16 possible binary combinations. If the register powers up in an invalid state (like 0000, 0101, 1010...), it will get "stuck" circulating that invalid pattern forever. A preset/initialize circuit (SET pin on one FF, CLEAR on rest) is always required in real hardware.
✅ Advantages: Simple decoding — any state needs just 1 AND gate. Self-timing, no glitches.
❌ Disadvantages: Wastes states — only N valid states from 2^N total. Needs initialization circuit.
🔧 Applications: Stepper motor control, sequential LED chasers, ring oscillators, CPU pipeline stage control.

Johnson Counter

Also called a Twisted Ring Counter. Feedback path uses the inverted (complemented) output Q3̄ instead of the true Q3.

🔑 Core Idea: Like the Ring Counter, but with a twist! Instead of the ball circulating, imagine a fill-and-drain cycle: first all 4 slots fill up with "1"s (one per clock), then all drain back to "0"s. This gives 2N = 8 states from 4 flip-flops — double that of a Ring Counter.

How It Works

  • Built from N D Flip-Flops in series — same as Ring Counter
  • Key difference: D0 = Q3' (inverted / complemented output of FF3)
  • When Q3=0 → Q3'=1 → next D0=1 (register fills with 1s)
  • When Q3=1 → Q3'=0 → next D0=0 (register empties with 0s)
  • Starting from 0000: 1s fill left-to-right, then 0s fill left-to-right
  • 4-stage Johnson counter has exactly 8 unique states (= 2N states)
  • Each adjacent pair of states differs by only 1 bit (Gray-code like)

Arduino Hardware Implementation Examples

Apply sequential logic concepts in real-world microprocessor circuits using the standard 74HC595 8-bit Shift Register integrated chip with Arduino platforms!

Writing Bits to 74HC595 (SIPO Shift Register)

int latchPin = 5; // ST_CP (Latch pulse)
int clockPin = 6; // SH_CP (Clock pulse)
int dataPin = 4;  // DS (Serial Input Pin)

void setup() {
  pinMode(latchPin, OUTPUT);
  pinMode(clockPin, OUTPUT);
  pinMode(dataPin, OUTPUT);
}

void loop() {
  // Cycle through numbers 0 to 255
  for (int numberToDisplay = 0; numberToDisplay < 256; numberToDisplay++) {
    // Ground latch pin and hold low while transmitting
    digitalWrite(latchPin, LOW);
    
    // Shift out the bits serially (MSBFIRST)
    shiftOut(dataPin, clockPin, MSBFIRST, numberToDisplay);
    
    // Return latch pin High to commit outputs in parallel
    digitalWrite(latchPin, HIGH);
    delay(500);
  }
}

Simulating MOD-10 BCD Counter

const int ledPins[4] = {8, 9, 10, 11}; // Q0, Q1, Q2, Q3
int count = 0;
const int MOD = 10; // Decade counter limit

void setup() {
  for (int i = 0; i < 4; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void loop() {
  // Expose count to 4-bit output pins
  for (int i = 0; i < 4; i++) {
    digitalWrite(ledPins[i], (count >> i) & 1);
  }
  
  delay(1000); // 1Hz clock interval
  
  count++; // Increment state
  
  // MOD Reset logic
  if (count >= MOD) {
    count = 0; // Wrap count back to 0
  }
}
