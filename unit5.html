Latch 1

SR Latch

The fundamental memory cell — two cross-coupled gates with Set and Reset inputs. Available in NOR and NAND variants.

SR Latch — NOR Gate Implementation

State: HOLD — Q=0, Q̄=1
S=0, R=0 → Both NOR inputs from S and R are 0. Outputs maintain previous state through cross-feedback.

⚠️ S=R=1 forces both NOR outputs to 0. When inputs return to 0,0 final state is unpredictable (race condition).

SR Latch — NAND Gate Implementation (Active-Low)

State: HOLD — Q=1, Q̄=0
S̄=R̄=1: Both NAND inputs from feedback prevent change. Outputs maintained by cross-coupled feedback.

⚠️ Invalid State Deep Dive

  • Both NOR gates see a HIGH input → both outputs forced to 0
  • Q = Q̄ = 0 violates the complementary rule
  • When S,R return to 0,0 → outputs race to random stable state
  • This unpredictability is called a race condition
Always ensure S·R = 0 in SR latch designs!

Latch 2

D Latch

Eliminates the invalid state by ensuring S and R are always complements via an inverter. Single D input + Enable (EN) control.

D Latch — Gate-Level (4-NAND Implementation)

EN=0 → Latch disabled, Q holds
EN=0: Both NAND gates (S̄/R̄ arms) output 1 regardless of D. The cross-coupled NAND latch holds its state.

💡 Why D Latch fixes Invalid State

The NOT gate ensures S̄ and R̄ are always complements — so S=R=1 (NOR invalid) can never happen.

Q(n+1) = D  (when EN=1)
Q(n+1) = Q  (when EN=0)
🚪 Analogy: EN is a door. When EN=1 (open), D walks in and sets Q. When EN=0 (closed), Q is sealed inside.

Advanced

Master-Slave JK Flip-Flop

Solves the race-around condition using two JK FFs in series. Master samples on CLK↑, Slave copies on CLK↓. Output only changes on falling edge.

Master-Slave JK FF — Step-by-Step Animator

1
CLK goes HIGH — Master FF is enabled. Reads J, K, and current Q. Computes next state internally.
2
CLK goes LOW — Master is disabled. Slave is now enabled. Slave copies Master's stored state → Q output updates.
3
Race-Around Fixed: Master and Slave are never active simultaneously. Q cannot feed back while Master is sampling.
