2's Complement Subtraction

A − B = A + (2's comp of B)

Steps:
1. Find 1's comp of B (flip bits)
2. Add 1 → gives 2's comp
3. Add result to A
4. If carry out → discard it
5. Result is positive ✅
This is how ALL modern CPUs subtract numbers!

Topic 3

Digital Codes

BCD · Excess-3 · Gray Code — special encoding schemes for digital systems.

BCD (Binary Coded Decimal)

Each decimal digit (0–9) is stored as its 4-bit binary value. Used in digital clocks and calculators.

Decimal 39:
3 → 0011
9 → 1001
BCD = 0011 1001
⚠️ Codes 1010–1111 are invalid in BCD.

Excess-3 (XS-3)

Add 3 (0011₂) to each BCD digit. Self-complementing — complement gives 9's complement automatically.

Decimal 39:
3+3=6 → 0110
9+3=12 → 1100
XS-3 = 0110 1100
9's complement of XS-3 digit = 1's complement. Very useful for subtraction!

Gray Code

Only ONE bit changes between consecutive numbers. Used in shaft encoders to avoid reading errors during transitions.

Binary → Gray:
MSB stays same.
Each next bit = XOR of
adjacent binary bits.

0011 → 0010
0100 → 0110

Topic 4

Complements

1's Complement and 2's Complement — the foundation of negative number representation in computers.

1's Complement

Flip every bit: 0 → 1 and 1 → 0. Simple bitwise NOT operation.

Binary:  1 0 1 1 0 1
Flip:  ↓ ↓ ↓ ↓ ↓ ↓
1's comp: 0 1 0 0 1 0
Has two representations of zero: 0000…0 and 1111…1

2's Complement

Take 1's complement, then add 1. The standard way computers represent negative numbers.

Binary: 1 0 1 1 0 1
1's comp: 0 1 0 0 1 0
Add 1: + 1
──────────────────
2's comp: 0 1 0 0 1 1
✅ Only one representation of zero. Used in all CPUs.

De Morgan's Theorem 1

(A · B)' = A' + B'

The complement of a product equals the sum of the complements.

NAND gate truth table confirms this:
A=1, B=1: (1·1)' = 0 = 1'+1' = 0+0 = 0 ✓
A=1, B=0: (1·0)' = 1 = 1'+0' = 0+1 = 1 ✓

De Morgan's Theorem 2

(A + B)' = A' · B'

The complement of a sum equals the product of the complements.

NOR gate truth table confirms this:
A=0, B=0: (0+0)' = 1 = 0'·0' = 1·1 = 1 ✓
A=1, B=0: (1+0)' = 0 = 1'·0' = 0·1 = 0 ✓

How to Apply De Morgan's

  1. Complement the entire expression
  2. Change AND (·) to OR (+) and vice versa
  3. Complement each individual variable
(A·B·C)' = A' + B' + C'
(A+B+C)' = A'·B'·C'

Example 1: Simplify AB + AB'

AB + AB'
= A(B + B')   [Distributive]
= A(1)       [B+B' = 1]
= A          [Identity]

Example 2: Simplify A + A'B

A + A'B
= (A+A')(A+B)  [Distributive]
= 1·(A+B)      [A+A'=1]
= A + B        [Identity]

Example 3: Simplify (A+B)(A+B')

(A+B)(A+B')
= A·A + A·B' + B·A + B·B'
= A + AB' + AB + 0
= A + A(B'+B)
= A + A·1 = A + A
= A

Example 4: Simplify ABC + ABC'

ABC + ABC'
= AB(C + C')  [Distributive]
= AB(1)       [C+C'=1]
= AB        [Identity]

Topic 7

SOP and POS Forms

Sum of Products and Product of Sums — two standard forms for any Boolean expression.

SOP – Sum of Products

An OR of AND terms. Each AND term is a minterm (row where F=1).

  1. List rows where F = 1
  2. For each row, write AND term (A' if bit=0, A if bit=1)
  3. OR all terms: F = Σm(...)
F = 1 at rows m1, m2, m3
m1 = A'B   m2 = AB'   m3 = AB
SOP: F = A'B + AB' + AB

POS – Product of Sums

An AND of OR terms. Each OR term is a maxterm (row where F=0).

  1. List rows where F = 0
  2. For each row, write OR term (A if bit=0, A' if bit=1)
  3. AND all terms: F = ΠM(...)
F = 0 at row m0 (A=0,B=0)
M0 = (A+B)
POS: F = (A+B)

Topic 8

Karnaugh Map (K-Map)

A visual method to simplify Boolean expressions by grouping adjacent 1s in a Gray-coded grid.

Rules for K-Map Grouping

  • Group only 1s (not 0s)
  • Group sizes must be powers of 2: 1, 2, 4, 8, 16
  • Groups can wrap around edges (it's a torus!)
  • Larger groups = simpler expression
  • Each 1 must be covered by at least one group
  • Each group → one product term (remove varying variables)
Always use the LARGEST possible groups first!

4-Variable K-Map Layout

Rows: CD in Gray order (00,01,11,10) · Cols: AB in Gray order

CD\AB  | 00 | 01 | 11 | 10
──────┼────┼────┼────┼───
00     | m0 | m4 |m12 | m8
01     | m1 | m5 |m13 | m9
11     | m3 | m7 |m15 |m11
10     | m2 | m6 |m14 |m10
⚠️ Columns are in GRAY order (00→01→11→10), NOT binary order!
